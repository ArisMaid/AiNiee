# 直接显示脚本文字（0.31）

2026-10-21，Codex。E03 增量，完整任务仍为部分实现。
复用已有 Acorn 字符串/模板片段、字节写回和 AST/未批准字节审计，不增加函数调用

## 来源和范围

对当前 168 条启用登记对应的 167 个不同脚本作只读解析，查找指定显示调用名的
直接字符串参数。得到 16 个含日文/CJK 的片段，全部为 `$TM.show` 的第一个参数。
这只是该有限扫描的结果：不包含任意拼接表达式、别名、动态回调、所有事件脚本
或所有语言；不能当作全游戏文字覆盖率。

| 当前消费者 | 获批片段 | 依据与保留边界 |
| --- | ---: | --- |
| SH_AddChapter | 1 | 目标变化提示；章节号、目标变量和重复判定不改 |
| SH_AddMiasmaCommon / handleTemporaryStates | 2 | 污染量与临时影响提示；数值和状态处理不改 |
| SH_BenriCommands 的 AddPurpose 注册回调 | 1 | 目标更新提示；写入变量的参数原值保持 |
| SH_ChangeEquipMessage | 6 | 四条穿衣提示的固定片段；完整角色控制码、衣物名表达式和条件不改 |
| SH_EnemySkillCount / SH_AfterSkill | 2 | 战斗提示；倒计时、状态、MP 与参数计算不改 |
| getParamUpItem / SH_EventResultTotal | 2 | 额外获得和魅力修正提示；物品 ID、概率、数量、金币计算不改 |
| SH_OpenLocation | 0，保留 2 | 原模板的颜色指令跨动态表达式，整条提示暂保留原文；不把不完整控制码拆进翻译 |

最后一项采用明确产品约定：本版没有该条提示的汉化承诺，后续需要时单独处理
完整模板。不扩展 TokenPolicy 以猜测半个指令，也不关闭检查。原调用的其他参数、
所有 `${...}` 表达式、条件、逻辑/资源字符串保持。身份和资源文字仍不因含日文开放。

额外获得分支不是无调用的死文字。当前技能 1279 的原 note 含 20% 全属性道具
加成，原 SH_PropertyTotalSkills 从已学技能读取；Map023 有 hp 调用，原事件结果
处理也调用该函数。消费者 VM 用原 DataManager.extractMetadata 解析该真实技能，
显式学会/未学会和固定随机值分别观察到数量 2/1 与提示有/无。固定随机值只是
正反例准备，不声称自然玩法触发；Map175 的另一个参数变体没有据此修复原游戏。

## 实现和使用约定

`source_spans` 是 profile-3 的显式权限：精确 JS 文件、解码源 SHA-256、每个区间
的稳定 ID、UTF-8 字节起止、AST 节点种类和文字 SHA-256。object_path 在该模式
是身份命名空间，不冒充对象绑定选择器。不能与对象/嵌套 JSON 选择混用。

提取先核对整份源指纹，再复用既有 extract_spans 确认范围恰好是字符串节点或
模板静态片段；写回继续使用同一 JS 编译/编码、AST 和未批准字节审计。普通对象
规则不变；本批有既有字典的同文件写入也必须合并审核。没有新通用调用解析器、
字典搜索回退、自动批准、游戏脚本执行或新恢复协议。

新增能力 `js_source_spans_v1` 同时由 profile 声明及实际 occurrence 推导。旧版本
不能理解此权限，0.30 实际 EXE 已通过 CLI summary 验证拒绝新工程、指明缺少该
能力，拒绝前后 DB 字节相同。请保留旧工程备份；已使用新版规则的工程用 0.31
及以后的相应版本打开，不要删能力字段强行降级。

换游戏版本或修改源插件后，指纹不符会要求重新审查规则。这是维护 SOP，无自动
偏移搜索或相似匹配兜底。普通译文编辑不需要人工计算字节地址；维护规则的人
负责审核源版本、调用用途和准确区间。
