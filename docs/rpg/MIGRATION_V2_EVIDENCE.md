# 迁移第二阶段验收

2026-10-17，0.4.0-dev 源码。范围为当前 MZ 游戏、受控版本差异和合成样例；
没有第二款真实游戏或该游戏其他实际发行版本的验收证据。

已实现完整位置匹配和双向唯一场景锚点匹配。同一文件、同一场景内插入事件后，
后续原文可能移到原先被其他文字占用的位置；先全局保留可靠配对，再分类新增/修改，
避免将移位误判为改文。锚点保留类型、说话人、逻辑字段、作用域和关联位置数量，
不采用模糊字符串。JS 数组索引可以移位，命名字段和函数绑定仍保留。

双方已声明的游戏 ID、引擎或目标语言不同会拒绝。缺少可验证 ID 时只出诊断，
不猜测谱系；当前自动应用仅支持 zh-CN。缺少 game_id 的旧 MV 工程仍需后续的明确
谱系机制，不能据本次结果宣称全部 MV 更新都可自动迁移。

五类对账为 reused/new/modified/orphaned/conflict。每个目标恰落入一类目标结果，
旧单元无唯一对应时单独列为 orphaned。reused 是待应用的可靠复用方案，不等于已提交。
OLD_UNTRANSLATED 表示没有可复用旧译文，不能将其误报为源文件损坏。

新增且未用于实际文本的控制符声明不再一律阻断迁移；比较双方对原文和译文的
真实控制符序列，并运行双方内容守卫。旧未知控制符、标记解释改变、过期译文、
目标锁定或已有译文仍不自动覆盖。CLI 按固定路径顺序持有两个工程锁；应用时重算
方案，先整体预检，再在逐条提交前复核旧值和目标 revision。中途变动会停止后续提交，
此前已接受的数据保留，不宣称跨两个数据库的批次原子事务。
