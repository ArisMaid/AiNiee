## 回写防护

审查发现旧 command_text_fields 可把355/655/356脚本或命令行当普通字符串。
现在 profile 与直接事件提取器均拒绝这些覆盖；通用 json_rules 也不能选中已知事件
中的脚本、条件、变量操作、移动路线、编辑注释或357调用身份槽位。
原生 patch_json 和兼容后端共用的 compile_json_changes 再检查实际命令与参数位置，
旧库中的未编码脚本单元也会在构建时拒绝，不发布成品。自定义 JSON 的同名 code 不误判。

已有受限 code122 字符串编解码保持：只允许精确单变量赋值[变量,同变量,0,4,原表达式]
的第4参数，表达式仍须为可解码字符串字面量。伪挂 codec 到脚本、不同变量、加算或布尔
编号均拒绝。正常对话、357显示参数、现有 JS 字节区间规则不受影响。

提取缓存算法升级至 rpg-extraction-event-write-guard-v2，写入计划升级至
rpg-build-event-write-guard-v5。旧工程可读；旧算法未完成的提取/构建须重新开始，
避免复用安全检查前的缓存。已交付的旧版本目录不修改。
