# 0.16 界面流程与性能证据

2026-10-18，Windows x64 源码验收。F01 仍为部分实现；本文不授予全游戏、真实模型或
所有性能指标通过的结论。0.15 已交付包保持不变，0.16 便携包需另行验收。

## 实现与审查

- 原有按钮对象和回调保留，按常用操作、工具与恢复、Translator++ 三页布局。
- 最近构建只从 SQLite 读取一条标量摘要，不把完整历史清单带进刷新结果。核验时读取
  一份完整登记，以工程登记核对清单、完成标记、逐文件 SHA-256 和额外文件；外部修改
  清单中的 hash 不能绕过登记。跨工程或已被替换的界面引用会拒绝操作。
- 文件核验有独立可暂停/取消任务；校验后请求打开目录，保持 runtime_validation=not_run。
- 后台线程只准备一个分离的缓存投影；GUI 主线程接管并更新视图，不再第二次查询整个
  数据图。载入失败、取消或翻译状态改变时保留旧缓存；取消意图保留到队列结果处理完，
  避免 QThread 返回后清除中断标志造成迟到结果被接管。
- Windows 主题监听由阻塞监听改为可中断轮询；关闭先请求退出并等待，停止失败时拒绝
  销毁窗口。没有 QThread.terminate。缓存写失败保留独立暂存，不循环删除。

DeepSeek 分别实现了布局/摘要、缓存准备接管及写入、后台加载器和主题轮询。最后一项
采用600秒上限，96.701秒完成，guard ready，无拒绝或保护测试改动。Codex 独立审查时
修复其主题回调缺少参数及导入错误未被捕获的问题，并补齐取消竞争、主窗口集成、登记
核验和验收测试。Worker 的 verified:false 不是验收结果；私有日志不随源码或包分发。

## 真实游戏工程与连续流程

本轮新建目录，未复用既有图来代替扫描/提取。原游戏9570文件、1,804,940,725字节。
Windows Qt 平台为 windows，QTest 操作真实主窗口、按钮、表格及编辑对话框。文件选择
使用 Qt 非原生对话框；其 UI 路径确实执行，但不代表 Windows 原生选择器已验收。

流程包括：选择三个目录；扫描后暂停（SQLite确认PAUSED）、继续（RUNNING）、取消；
重新打开生成的 game-project.json 并恢复扫描；提取；以无效控制符人工样例验证拒绝；
从问题列表选回已被筛掉的单元；使用中文输入法事件人工编辑并锁定；导出全部文本；
导入另一人工样例；选择工程字体；离线校验；测试构建；按登记校验副本；再次核验并
请求 Windows 打开目录；载入 AiNiee 翻译视图，检查中文和锁仍存在。未启动翻译任务。

新提取为 **17710个文本单元**。既有profile5图中的17716个单元，额外6个都是此前确认的
image-text区域；其余文本ID集合一致。这6个区域不是自动文本提取的产物。

本轮2条人工译文，控制符错误为TOKEN_MISMATCH且未接纳；测试输出9570个清单文件，
build_id=60231d17deb14bb9b53148cb4c0345fc，仍有17708个未译文本单元。运行期状态未升级。
目录打开返回系统接受；未检查 Explorer 内容。原游戏全文件集合/hash及主profile5数据库
保持，进程exit=0，主题线程正常停止。截图经过Codex目视检查，均保存在私有work目录。
