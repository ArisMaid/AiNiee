# 当前游戏 profile 3：显示字面量与函数词表

核验日期：2026-10-17。源码版本：0.3.0-dev。当前游戏仍是 MZ 1.7.0 / α 0.141；
其他真实游戏按用户决定后置。本文只记录本增量，不声明完整计划或全游戏汉化完成。

## 实现范围

| 来源 | 批准的显示字段 | 排除边界与消费者依据 |
|---|---|---|
| CommonEvents / code 122 | 指定事件 1950、1975、1995 内变量 1938 的十个完整 JSON 字符串表达式 | 仅单变量、赋值、脚本操作数固定形状；不解析拼接、任意脚本或其他变量。实际消费者是搜索条件与 DTextPicture 标题 |
| SH_Consts / NEWS_Text | 直接函数体内 args 字典的 title、text，共 16 项 | tag、对象键和逻辑字段不变；CommonEvents 118、1956 获取显示文本 |
| SH_Consts / SH_LocVar | 直接函数体内 args 字典的 name、note，共 55 项 | id、enemyFlag 等逻辑字段不变；地图通知和 SH_MapNoteVar 使用显示值 |
| TalkList | 不新增翻译单元 | 当前消费者按 id/pattern 选择音频 file；未找到 actor/group 的显示读取，不能仅因含日文就翻译 |

新增 81 项；独立工程合计 17706 项（含六个图片单元）。继承 19 条已验收演示译文，
本次再提交六条，总计 25 条，17681 条未译，14 条未知控制符仍阻断。
原有 profile 2 工程数据库 SHA 不变，图片预览重新生成后的 SHA 与已审查版本一致。

事件原文单元保存解码后的显示文字，occurrence 保存原始带引号表达式及其 hash。
所有原生和第三方回写先验证该 hash，再编码为完整 JSON 字符串；未变化时保留原始
空白和转义字节。不会把译文直接拼入可执行表达式。源码分析不执行游戏脚本。
旧的 Kd.words 静态箭头 IIFE 继续提取 65 项，普通函数、回调、遮蔽根绑定不会被误选。

变量 1938 的显示值同时参与零比较；守卫保持 JS Number-zero 类别和字符串真值，
防止将非空零字符串改为空串后，被 Game_Variables.value 的 `value || 0` 改变类型。
地点 note 按 LF 拆分后写入从 1521 开始的连续变量槽，译文必须保留换行数量，
避免写到额外槽位。是否需要更宽的布局仍需具体窗口验证。

## 工程兼容与备份

profile schema 为 3；物理 SQLite schema 仍为 2。新能力包括 event_js_string_v1、
js_scoped_object_v1、display_line_count_v1，连同既有能力由共享清单验证。
未知能力、未声明的活动能力、非法 selector 和重复写入所有权都拒绝。
迁移的 JS 定位纳入函数作用域，防止同一文件不同函数的同名 args 字段串译；
缺失作用域与非法/null/冲突作用域分别处理，旧全局对象定位保持兼容。
提取单元、策略和能力在同一事务提交；失败不遗留半更新规则。

既有格式 2 工程增加能力前，通过 SQLite backup API 保留已提交状态，路径为
`migrations/capabilities-v2/<UUID>/project.sqlite3`。备份失败则中止升级；
升级后的事务失败仍回滚。普通读取和无新增能力的重提取不创建新备份。
备份用于原工程恢复，不含完整 source/图片/字体，不能当作独立构建工程。
旧 0.2 EXE 已实测拒绝这些能力，拒绝前后数据库 SHA 一致。
旧构建写入计划不能由新版本继续恢复。
